Group 3 MVP User Flow

Real-Time PC Reservation System Map

Interactive User Flow Diagram from Entry Point to Feedback Pass

Screen 1 (Entry)

Login & Dashboard

Student views live status of all Computer Labs.

Screen 2 (Main Action)

PC Selection & Slot

Pick an open workstation & select reservation time.

Decision Point

Validate Availability

Backend checks if workstation is free for chosen time.

Screen 3 (Feedback)

Confirmation & Pass

Generates digital QR entry code and booking receipt.

Fallback Loop: If the selected PC becomes unavailable during booking, the system redirects the user back to Screen 2 to select another open slot.
